## Specification
Cree `crates/puce-m68k/src/regs.rs` (`pub mod regs;`): `#[derive(Clone, Copy, Debug, Default, PartialEq, Eq)] pub struct Regs { pub d: [u32; 8], pub a: [u32; 7], pub usp: u32, pub ssp: u32, pub sr: u16, pub pc: u32, pub ir: u16, pub irc: u16 }`.
- Constantes de SR: `C=0x01, V=0x02, Z=0x04, N=0x08, X=0x10, IMASK=0x0700, S=0x2000, T=0x8000`, masque des bits valides `SR_MASK = 0xA71F`.
- `a7(&self) -> u32` (ssp si S sinon usp), `set_a7(&mut self, v)`, `an(&self, n: u8) -> u32` (n=7 -> a7), `set_an`.
- `set_sr(&mut self, v: u16)` applique `SR_MASK`; `ccr(&self) -> u8`; `set_ccr(&mut self, v: u8)` ne change que le poids faible.
- PC et adresses: 24 bits significatifs a l'usage (pas de masquage dans le type).

## 3. Etat

```
u32 numbytes, u32 magic = 0x01234567
19 x u32 dans l'ordre: d0..d7, a0..a6, usp, ssp, sr, pc
u32 prefetch0, u32 prefetch1        (file de prefetch: IR puis IRC)
u32 num_rams
num_rams x { u32 addr (pair, < 0x1000000), u16 data }    mot de 16 bits a l'adresse addr (octet haut a addr, bas a addr+1)
```
- `pc` = valeur de `m_au` de MAME = **adresse du prochain mot a prefetcher** = adresse de l'instruction + 4 (l'instruction et son premier mot d'extension sont deja dans la file `prefetch0`, `prefetch1`).
- Seule la memoire touchee par le test est listee; le reste est ignore (le lecteur doit fournir une RAM dont le contenu hors liste est sans effet sur le resultat).
- `a7` n'existe pas dans l'ordre: A7 est `usp` ou `ssp` selon le bit S de `sr`.

## Tests
Tous les tests sont prefixes par `e02_02_`.

- `e02_02_a7_user` : S=0: a7() = usp
- `e02_02_a7_super` : S=1: a7() = ssp
- `e02_02_set_a7` : set_a7 ecrit usp ou ssp selon S
- `e02_02_an_7` : an(7) == a7()
- `e02_02_sr_mask` : set_sr(0xFFFF) donne 0xA71F
- `e02_02_ccr` : set_ccr(0xFF) ne modifie pas l'octet haut de sr; ccr() = sr & 0x1F
