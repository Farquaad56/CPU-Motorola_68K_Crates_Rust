pub trait Bus {
    fn read(&mut self, addr: u32, fc: u8, uds: bool, lds: bool) -> u16;
    fn write(&mut self, addr: u32, fc: u8, uds: bool, lds: bool, data: u16);
    /// Extra wait clocks for the cycle that starts now (default 0 = DTACK immediate).
    fn wait_clocks(&mut self, _addr: u32, _write: bool) -> u8 { 0 }
    /// Called once per clock with the pins the CPU drives (peripheral clocks).

}

## 4. Echantillonnage

DTACK est echantillonne a l'horloge 3 de chaque cycle de bus (puis a chaque horloge d'attente). Un hote simple force DTACK = 1 en permanence (zero wait state). Un hote avec attentes dependantes de la phase (NeoGeo, specs/40) pilote DTACK lui-meme via `tick(pins)`; le trait `Bus::wait_clocks` ne sert que pour une attente decidee au debut du cycle.
