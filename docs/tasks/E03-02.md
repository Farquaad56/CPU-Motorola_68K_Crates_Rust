# E03-02 - Machine RAM plate (FlatRam)
Epopee: E03 | Type: code | Dependances: E03-01 | Taille estimee: ~100 lignes

## Contexte
RAM 16 Mio pour le runner et les futures machines. Remise a zero rapide entre deux tests: on ne reinitialise que les mots touches.

## Specification
Dans `crates/puce-m68k-machines/src/flat.rs`: `pub struct FlatRam { mem: Box<[u8]> /* 16 MiB */, touched: Vec<u32> }`, `FlatRam::new()`,
`impl puce_m68k::bus::Bus for FlatRam` (adresse masquee a 24 bits; `read` renvoie le mot a `addr & !1` en tenant compte de `uds`/`lds`: octet non selectionne = 0; `write` n'ecrit que les octets selectionnes et memorise l'adresse du mot dans `touched`),
`poke_word(addr, w)` / `peek_word(addr)` / `peek_byte` (sans journal), `clear_touched(&mut self)` (remet a zero tous les mots touches puis vide la liste).
Les acces sont toujours alignes sur le mot dans cette machine (l'octet 'haut' est a l'adresse paire).


## Tests
Tous les tests sont prefixes par `e03_02_`.

- `e03_02_word_rw` : ecriture mot 0x1234 en 0x1000 puis lecture avec uds+lds = 0x1234
- `e03_02_byte_high` : ecriture avec uds seul de 0xAB00: octet a 0x1000 = 0xAB, 0x1001 inchange
- `e03_02_byte_low` : lds seul: octet a 0x1001
- `e03_02_read_selects` : lecture avec uds seul renvoie 0xAB00
- `e03_02_addr_mask` : 0xFF00_1000 equivaut a 0x00_1000
- `e03_02_clear_touched` : apres clear_touched la memoire ecrite vaut 0
