## Specification
Dans `crates/puce-m68k/src/state.rs` (`pub mod state;`): `pub struct CpuState { pub d: [u32; 8], pub a: [u32; 7], pub usp: u32, pub ssp: u32, pub sr: u16, pub pc: u32, pub prefetch: [u16; 2] }`.
Dans `cpu.rs`: `Cpu::load_state(&mut self, s: &CpuState)` (IR = prefetch[0], IRC = prefetch[1], le moteur est place a une frontiere d'instruction) et `Cpu::state(&self) -> CpuState`.
`Cpu::tick_bus<B: Bus>(&mut self, bus: &mut B)`: construit les broches d'entree (DTACK=1 sauf pendant les `bus.wait_clocks` du cycle courant; `bus.read` appele a l'horloge ou le CPU echantillonne les donnees, `bus.write` a l'horloge ou la donnee est valide), appelle `tick`, puis `bus.on_tick(out)`.
`Cpu::step_clocks<B: Bus>(&mut self, bus: &mut B, n: u32)` = n appels de `tick_bus`.

## 3. Etat

```
u32 numbytes, u32 magic = 0x01234567
19 x u32 dans l'ordre: d0..d7, a0..a6, usp, ssp, sr, pc
u32 prefetch0, u32 prefetch1        (file de prefetch: IR puis IRC)
u32 num_rams
num_rams x { u32 addr (pair, < 0x1000000), u16 data }    mot de 16 bits a l'adresse addr (octet haut a addr, bas a addr+1)
```
- `pc` = valeur de `m_au` de MAME = **adresse du prochain mot a prefetcher** = adresse de l'instruction + 4 (l'instruction et son premier mot d'extension sont deja dans la file `prefetch0`, `prefetch1`).
- Seule la memoire touchee par le test est listee; le reste est ignore (le lecteur doit fournir une RAM dont le contenu hors liste est sans effet sur le resultat).
- `a7` n'existe pas dans l'ordre: A7 est `usp` ou `ssp` selon le bit S de `sr`.

## Tests
Tous les tests sont prefixes par `e03_03_`.

- `e03_03_load_roundtrip` : load_state puis state() donne le meme CpuState
- `e03_03_ir_irc` : prefetch[0] -> regs.ir et prefetch[1] -> regs.irc
