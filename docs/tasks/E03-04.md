## Specification
Dans `crates/puce-m68k/src/probe.rs` (`#[cfg(feature = "inspect")] pub mod probe;`): `#[derive(Clone, Copy, Debug, Default, PartialEq, Eq)] pub struct BusEvent { pub kind: u8 /*0 idle,1 write,2 read,3 tas,4 re,5 we*/, pub clocks: u32, pub fc: u8, pub addr: u32, pub data: u16, pub uds: bool, pub lds: bool }`,
journal a taille fixe (`[BusEvent; 64]` + longueur) dans `Cpu`; `Cpu::journal(&self) -> &[BusEvent]`, `Cpu::clear_journal(&mut self)`.
Chaque cycle de bus execute (jeton R*/W*/Tas) ajoute un evenement; les jetons `N(n)` consecutifs fusionnent en un evenement idle. `clocks` inclut les wait states. Debordement: les evenements en trop sont comptes dans `Cpu::journal_overflow()`, pas stockes.

## 4. Transactions

```
u32 numbytes, u32 magic = 0x456789AB
u32 num_cycles            (= duree totale en horloges, champ `length` du test)
u32 num_transactions
num_transactions x:
    u8  kind, u32 cycles
    si kind != 0: u32 fc, u32 addr_bus, u32 data_bus, u32 uds, u32 lds
```

| kind | Nom | Sens |
|---|---|---|
| 0 | `n` | cycle interne de `cycles` horloges (pas d'autres champs) |
| 1 | `w` | ecriture |
| 2 | `r` | lecture |
| 3 | `t` | cycle TAS (RMW) |
| 4 | `re` | lecture avec address error (AS non asserte, resultat non committe) |
| 5 | `we` | ecriture avec address error |

- `data_bus` suit le bus reel: octet par UDS seul -> 0xAB00 (voir 11_PINS_AND_TICK.md).
- Taille `.w`/`.b` deduite de `uds + lds` (2 = mot).
- UNKNOWN - to confirm (a lever dans E03-01 en lisant les premiers tests): `addr_bus` est-il une adresse d'octet ou de mot (A1..A23)? `cycles` d'une transaction de bus est-il toujours >= 4?

## Tests
Tous les tests sont prefixes par `e03_04_`.

- `e03_04_read_event` : un cycle de lecture produit 1 evenement kind=2, clocks=4, adresse/fc/uds/lds corrects
- `e03_04_wait_included` : avec 2 horloges d'attente: clocks=6
- `e03_04_idle_merge` : N(2) puis N(4) = 1 evenement idle de 6
- `e03_04_overflow` : au-dela de 64 evenements le compteur de debordement augmente
- `e03_04_clear` : clear_journal vide la liste
- `e03_04_no_inspect_build` : le crate compile sans la feature (test de compilation par cargo build)
