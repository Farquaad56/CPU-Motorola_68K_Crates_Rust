# E03-06 - Runner: fichiers, repertoire, exceptions connues
Epopee: E03 | Type: code | Dependances: E03-05 | Taille estimee: ~140 lignes

## Contexte
Execute un fichier ou tout un repertoire, applique le filtre (stem exact ou epopee) et la liste d'exceptions connues, produit un resume.

## Lire d'abord
- `docs/specs/data/instructions.tsv` (colonnes stem, epic) et `docs/specs/data/sst_known_exceptions.txt`
- `docs/qa/DECISIONS.md` et `docs/qa/FAQ_M68K.md` (a consulter avant toute question)

## Write only in
- `crates/puce-m68k-machines/src/ssc.rs`
- `docs/qa/inbox/**` (questions uniquement)

## Specification
Dans `ssc.rs`: `pub struct FileSummary { pub stem: String, pub total: u32, pub passed: u32, pub failed: u32, pub skipped_addr_error: u32, pub first_failures: Vec<String> /* 5 max */ }`,
`pub fn run_file(path: &Path, cpu: &mut Cpu, ram: &mut FlatRam) -> Result<FileSummary, String>`,
`pub struct Selection { pub stems: Vec<String> /* vide = tous */ }`, `Selection::from_filters(&[String])` (un filtre = stem exact `ADD.b`, ou nom sans suffixe qui selectionne `NOM` et `NOM.*`), `Selection::from_epic(tsv: &Path, epic: &str)`,
`pub fn run_dir(dir: &Path, sel: &Selection) -> Result<Vec<FileSummary>, String>` (ordre alphabetique, erreur si un stem demande n'existe pas),
`pub fn load_known(path: &Path) -> Result<Vec<String>, String>` (premiere colonne tabulee, lignes vides ignorees),
`pub fn is_clean(s: &FileSummary, known: &[String]) -> bool` (vrai si `failed == 0` ou si le stem de base (avant le premier point) est dans `known`).


## Tests
Tous les tests sont prefixes par `e03_06_`.

- `e03_06_filter_exact` : filtre `ADD.b` ne selectionne que ADD.b
- `e03_06_filter_base` : filtre `ADD` selectionne ADD.b ADD.l ADD.w mais pas ADDA ni ADDX
- `e03_06_epic_select` : from_epic sur un tsv de test selectionne les bons stems
- `e03_06_known_parse` : load_known lit TAS et TRAPV du vrai fichier
- `e03_06_is_clean_known` : TAS avec 5 echecs est propre; ADD.b avec 1 echec ne l'est pas
- `e03_06_missing_stem` : stem inexistant -> Err
