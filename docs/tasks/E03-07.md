## Specification
Dans `crates/puce-m68k-cli/src/main.rs` et `commands.rs`: `m68k ssc <dir> [--filter F]... [--epic E06] [--strict] [--max-fail N] [--known FILE]` (`--filter` repetable; `--known` defaut `docs/specs/data/sst_known_exceptions.txt`; `--epic` lit `docs/specs/data/instructions.tsv`).
Sortie: une ligne par fichier `STEM total=2500 pass=.. fail=.. skip_addr=..`, les `first_failures` indentees sous les fichiers en echec, puis `TOTAL total=.. pass=.. fail=.. skip_addr=..`.
Code de sortie: 0 si pas de `--strict`; avec `--strict`: 1 si un fichier n'est pas `is_clean` (les echecs des stems connus ne comptent pas), sinon 0. `--max-fail N` arrete a N echecs au total.
Remplace le stub `ssc` (E01-03).


## Tests
Tous les tests sont prefixes par `e03_07_`.

- `e03_07_parse_ssc` : `m68k ssc tests/singlestep --filter NOP --strict` se parse
- `e03_07_parse_epic` : `--epic E06` accepte
- `e03_07_parse_filters` : deux `--filter` donnent deux filtres
- `e03_07_bad_flag` : flag inconnu -> erreur
- `e03_07_strict_exit` : fonction `exit_code(summaries, known, strict)`: 1 si un fichier non connu echoue, 0 si seul TAS echoue
