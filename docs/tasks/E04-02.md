# E04-02 - Decouper Yacht.txt en un fichier par instruction
Epopee: E04 | Type: tooling | Dependances: E04-01 | Taille estimee: ~150 lignes

## Contexte
Les cartes d'instruction embarquent leur spec de timing: il faut un fichier `docs/specs/instr/<MNEMONIQUE>.md` par instruction (contexte LLM 135000 tokens: un fichier = quelques centaines de lignes max). Le format de Yacht.txt n'est pas connu a l'avance: lis-le d'abord.

## Lire d'abord
- `docs/ref/Yacht.txt` (a lire en entier avant d'ecrire le script)
- `docs/specs/data/instructions.tsv` (liste des mnemoniques attendus, colonne `mnemonic`)
- `docs/qa/DECISIONS.md` et `docs/qa/FAQ_M68K.md` (a consulter avant toute question)

## Write only in
- `docs/tools/split_yacht.py`
- `docs/specs/instr/**`
- `docs/qa/inbox/**` (questions uniquement)

## Specification
Cree `docs/tools/split_yacht.py` (Python 3.8+, bibliotheque standard): decoupe Yacht.txt en `docs/specs/instr/<MNEMONIQUE>.md` (un fichier par mnemonique de la colonne `mnemonic`, y compris les variantes de taille dans le meme fichier), en gardant le texte original (copie fidele, avec un en-tete `# <MNEMONIQUE>` et la source `docs/ref/Yacht.txt` + numeros de lignes).
Options: `--check` verifie que chaque mnemonique de `instructions.tsv` a un fichier non vide et liste les manquants; sans option, regenere tout.
Les mnemoniques absents de Yacht.txt (ex. exceptions) sont listes dans `docs/specs/instr/MISSING.txt` avec la raison; ne devine rien.
