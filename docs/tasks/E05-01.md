# E05-01 - Table de decodage (65536 entrees, const fn)
Epopee: E05 | Type: code | Dependances: E04-04 | Taille estimee: ~130 lignes

## Contexte
Le coeur est `no_std` sans alloc: la table opcode -> instruction est construite a la compilation par une `const fn` a partir d'une liste de regles (masque, valeur) fournie par chaque module d'instruction.

## Specification
Cree `crates/puce-m68k/src/decode.rs` (`pub mod decode;`) et `crates/puce-m68k/src/insn/mod.rs` (`pub mod insn;`):
- `#[derive(Clone, Copy, PartialEq, Eq, Debug)] pub struct InsnId(pub u16);` avec `InsnId::ILLEGAL = InsnId(0)`.
- `pub struct Rule { pub mask: u16, pub value: u16, pub id: InsnId, pub variant: u8 }`.
- `pub const fn build_table(rules: &[Rule]) -> [Decoded; 65536]` ou `Decoded { id: InsnId, variant: u8 }`; une regle donne son (id, variant) a tout opcode `o` avec `o & mask == value`; deux regles qui capturent le meme opcode = `panic!` a la compilation (const), l'ordre n'est pas significatif.
- `pub static TABLE: [Decoded; 65536] = build_table(insn::RULES);` et `pub fn decode(op: u16) -> Decoded`.
- `insn/mod.rs`: `pub const RULES: &[Rule] = &[...]` (vide pour l'instant, chaque carte d'instruction ajoutera `.. mod::RULES` via une macro ou une concatenation const documentee).


## Tests
Tous les tests sont prefixes par `e05_01_`.

- `e05_01_empty_illegal` : table sans regle: tout opcode vaut ILLEGAL
- `e05_01_single_rule` : regle mask=0xFFFF value=0x4E71: decode(0x4E71) = id, decode(0x4E72) = ILLEGAL
- `e05_01_mask_range` : regle mask=0xF1F8 value=0x4000 capture 8 x 8 opcodes attendus (comptage)
- `e05_01_variant` : le `variant` de la regle est restitue
- `e05_01_table_size` : la table a 65536 entrees
- `e05_01_conflict_detected` : `build_table` sur deux regles recouvrantes panique (test `#[should_panic]` en const-eval via appel runtime de la meme fonction)
