# E05-02 - Champs d'adressage effectif et categories de validite
Epopee: E05 | Type: code | Dependances: E05-01 | Taille estimee: ~140 lignes

## Contexte
Decodage des 6 bits mode/registre d'un opcode et categories d'adressage du manuel (donnees, memoire, controle, alterable) utilisees par chaque instruction pour ses regles de decodage.

## Specification
Cree `crates/puce-m68k/src/ea.rs` (`pub mod ea;`): `pub enum Ea { DataReg(u8), AddrReg(u8), Ind(u8), PostInc(u8), PreDec(u8), Disp(u8), Index(u8), AbsW, AbsL, PcDisp, PcIndex, Imm }`, `Ea::decode(mode: u8, reg: u8) -> Option<Ea>` (None pour mode 7 reg 5..7).
Categories sous forme de fonctions `const fn is_data(mode, reg)`, `is_memory`, `is_control`, `is_alterable`, `is_data_alterable`, `is_memory_alterable`, `is_control_alterable` definies par le manuel: data = tout sauf An; memory = tout sauf Dn et An; control = (An), d16(An), d8(An,Xn), abs.W, abs.L, d16(PC), d8(PC,Xn); alterable = tout sauf d16(PC), d8(PC,Xn), #imm. Une `const fn ea_mask(f: fn(u8,u8)->bool) -> u64` renvoie un masque 64 bits indexe par `mode*8+reg` pour construire des regles.


## Tests
Tous les tests sont prefixes par `e05_02_`.

- `e05_02_decode_all_12` : les 12 modes decodent vers la bonne variante
- `e05_02_decode_invalid` : mode 7 reg 5, 6, 7 -> None
- `e05_02_data_excludes_an` : is_data(1, n) faux pour tout n
- `e05_02_memory_excludes_dn_an` : is_memory(0,n) et (1,n) faux
- `e05_02_control_list` : control = exactement 7 combinaisons de modes (2,5,6,7/0,7/1,7/2,7/3)
- `e05_02_alterable_excludes_pc_imm` : is_alterable(7,2), (7,3), (7,4) faux
- `e05_02_data_alterable_count` : nombre de combinaisons (mode,reg) data-alterable = 50 (Dn, (An), (An)+, -(An), d16(An), d8(An,Xn): 6x8, plus abs.W et abs.L)
- `e05_02_mask_bit` : ea_mask(is_data) a le bit (0*8+3) et pas le bit (1*8+3)
