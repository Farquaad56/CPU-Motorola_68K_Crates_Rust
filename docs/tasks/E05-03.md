# E05-03 - File de prefetch (IR/IRC) et jeton Pf
Epopee: E05 | Type: code | Dependances: E05-02 | Taille estimee: ~120 lignes

## Contexte
Le prefetch rend les cycles de bus exacts: IRC contient le mot suivant, IR l'instruction en cours; chaque `Pf` fait avancer la file.

## Specification
Dans le moteur (`engine/mod.rs`, `cpu.rs`): implemente l'effet du jeton `Pf`: lit le mot a l'adresse `regs.pc` avec FC = programme (superviseur `6` si SR.S, sinon utilisateur `2`), `regs.ir = regs.irc; regs.irc = mot lu; regs.pc += 2` (l'adresse est celle du prochain mot a prefetcher, cf. specs/33). Au tick de lecture de donnee du cycle, pas avant.
Ajoute `AddrSrc::Pc` dans la resolution d'adresse. Le journal inspect (E03-04) enregistre le Pf comme une lecture FC programme.
Ajoute aussi la lecture d'un mot d'extension: `Cpu::ext_word(&self) -> u16` = `regs.irc` (avant le Pf qui le consomme).

## 2. Jetons

| Jeton | Duree (horloges) | Effet bus |
|---|---|---|
| `N(n)` | n (pair) | cycle interne, aucune activite de bus |
| `Pf` | 4 | prefetch: lit le mot a l'adresse `PC` (FC = programme), IRC -> IR puis mot lu -> IRC, `PC += 2` |
| `Rb(addr)` / `Rw(addr)` | 4 | lecture octet / mot a l'adresse source (FC donnees) |
| `Wb(addr,val)` / `Ww(addr,val)` | 4 | ecriture octet / mot |
| `Rl(addr)` / `Wl(addr,val)` | 8 | mot haut puis mot bas (deux cycles de bus enchaines) |
| `Tas` | 4 (RMW) | cycle indivisible lecture-modification-ecriture de TAS (UNKNOWN - to confirm: 5 cycles?) |
| `H(k)` | 0 | appelle le hook `k` (semantique) sans consommer d'horloge |

`addr` est une source d'adresse symbolique: `Pc`, `Ea`, `EaPlus2`, `An(n)`, `AnPre(n)` (pre-decrement), `AnPost(n)` (post-increment), `Sp`, `SpPre`, `SpPost`, `Vec(n)`. UNKNOWN - to confirm: liste definitive (E02-04).

## Tests
Tous les tests sont prefixes par `e05_03_`.

- `e05_03_pf_shifts_queue` : apres un Pf: ir = ancien irc, irc = mot lu
- `e05_03_pf_advances_pc` : pc += 2
- `e05_03_pf_fc_super` : SR.S=1: FC=6
- `e05_03_pf_fc_user` : SR.S=0: FC=2
- `e05_03_pf_address` : le mot est lu a l'ancien pc
- `e05_03_pf_4_clocks` : un Pf dure 4 horloges, 6 avec 2 waits
- `e05_03_ext_word` : ext_word() = irc
