# E05-04a - Plans d'adresse effective: Dn, An, (An), (An)+, -(An)
Epopee: E05 | Type: code | Dependances: E05-03 | Taille estimee: ~140 lignes

## Contexte
Fonctions qui renvoient le plan de micro-cycles pour calculer une adresse effective et lire/ecrire l'operande, modes simples. Timing: `docs/specs/instr/_EA.md` (E04-03). Si ce fichier contient UNKNOWN pour un mode, pose la question Q&R, ne devine pas.

## Specification
Dans `crates/puce-m68k/src/ea.rs`: `pub fn ea_read_plan(ea: Ea, size: Size) -> Plan` et `pub fn ea_write_plan(ea: Ea, size: Size) -> Plan` (plans `&'static [Tok]`, via des `static` ou une `const fn` documentee) pour `DataReg`, `AddrReg`, `Ind`, `PostInc`, `PreDec`. `pub enum Size { Byte, Word, Long }`.
Le pre-decrement ajoute son cycle interne selon `_EA.md`; (An)+ et -(An) sur A7 en octet changent de 2 (a gerer dans le hook, pas dans le plan: documente-le).
