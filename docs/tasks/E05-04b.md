# E05-04b - Plans d'adresse effective: d16(An), d8(An,Xn), abs, PC-relatif, immediat
Epopee: E05 | Type: code | Dependances: E05-04a | Taille estimee: ~150 lignes

## Contexte
Suite de E05-04a: modes avec mot(s) d'extension (prefetch) et calcul d'index.

## Specification
Complete `ea_read_plan`/`ea_write_plan` pour `Disp`, `Index`, `AbsW`, `AbsL`, `PcDisp`, `PcIndex`, `Imm` (immediat: taille octet/mot = 1 mot d'extension, long = 2). Chaque mot d'extension est un `Pf` (E05-03) place comme dans `_EA.md`; l'index `d8(An,Xn)` ajoute le cycle interne indique.
`ea_ext_words(ea: Ea, size: Size) -> u8` renvoie le nombre de mots d'extension (0, 1 ou 2).


## Tests
Tous les tests sont prefixes par `e05_04b_`.

- `e05_04b_disp_word_read` : d16(An) lecture mot: 1 Pf + 1 Rw (duree selon _EA.md)
- `e05_04b_index_internal` : d8(An,Xn): contient un N(2)
- `e05_04b_abs_w_long` : abs.W lecture long: 1 Pf + Rl
- `e05_04b_abs_l_ext_words` : abs.L = 2 mots d'extension
- `e05_04b_imm_long_ext_words` : #imm long = 2 mots; octet = 1
- `e05_04b_pc_disp` : d16(PC) lecture mot
- `e05_04b_ext_words_table` : ea_ext_words pour les 12 modes
