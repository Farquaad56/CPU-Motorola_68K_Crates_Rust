# E05-05 - Boucle d'instruction: decodage et execution (step)
Epopee: E05 | Type: code | Dependances: E05-04b | Taille estimee: ~140 lignes

## Contexte
Relie decodage, plans et semantique: a la frontiere d'instruction, decoder IR, choisir le plan (insn, variante) et l'executer; `step` = executer une instruction complete.

## Specification
Dans `cpu.rs`/`engine/mod.rs`: `fn begin_instruction(&mut self)` lit `decode::decode(self.regs.ir)`; si `ILLEGAL`, place le moteur en etat `Illegal` (journalise, aucune exception avant E11: il n'avance pas et `at_instruction_boundary()` reste vrai; documente-le). Sinon appelle `insn::plan_for(id, variant, &mut self)` qui renvoie le `Plan` (dispatch par `match id` dans `insn/mod.rs`, vide pour l'instant: renvoie un plan `&[Tok::Pf]` par defaut seulement pour `InsnId` de test).
`pub fn step<B: Bus>(&mut self, bus: &mut B) -> u32` execute jusqu'a la prochaine frontiere d'instruction et renvoie les horloges consommees (une instruction ILLEGAL renvoie 0).
Les hooks `H(k)` sont dispatches par `insn::run_hook(id, k, &mut Cpu)`.


## Tests
Tous les tests sont prefixes par `e05_05_`.

- `e05_05_illegal_no_advance` : opcode ILLEGAL: step renvoie 0
- `e05_05_test_insn_runs` : une instruction de test enregistree (feature de test) s'execute et step renvoie la duree du plan
- `e05_05_boundary` : at_instruction_boundary vrai apres step
- `e05_05_hook_dispatch` : un hook de test est appele une fois a la bonne position
- `e05_05_step_counts_waits` : avec wait states: la valeur renvoyee les inclut
