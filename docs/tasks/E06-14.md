## Specification
Implemente `CLR` (b, l, w) dans `crates/puce-m68k/src/insn/i_clr.rs` et enregistre-la dans `insn/mod.rs` (`pub mod i_clr;`, ses `RULES`, sa branche de `plan_for` et de `run_hook`).
Sous-taches, dans cet ordre:
1. Decodage: regles (masque, valeur) de tous les encodages LEGAUX de CLR (modes d'adressage valides via `ea.rs`); les autres encodages ne doivent pas etre captures.
2. Plans: pour chaque (taille, mode source, mode destination) legal, un plan de micro-cycles (jetons de `docs/specs/12_PLAN_GRAMMAR.md`, `ea_read_plan`/`ea_write_plan` de `ea.rs`) conforme a `docs/specs/instr/CLR.md`.
3. Semantique et drapeaux (X N Z V C) dans les hooks; fonctions pures partagees dans `alu.rs` si elles servent a plusieurs instructions.
4. Verification: la commande `m68k ssc ... --strict` ci-dessous doit passer (2500 tests par fichier; tests avec address error ignores, D-030).
Source de verite du timing: `docs/specs/instr/CLR.md` puis `docs/specs/instr/_EA.md`. Jamais deviner un timing: question Q&R avec les valeurs en conflit. Les tests SingleStepTests viennent de MAME (D-007).

## Tests
Tous les tests sont prefixes par `e06_14_`.

- `e06_14_decode_legal` : tous les encodages legaux de CLR decodent vers cette instruction (comptage exact attendu: calcule-le d'apres les modes valides)
- `e06_14_decode_illegal` : un encodage illegal voisin n'est pas capture
- `e06_14_plan_basic` : le plan du cas le plus simple a la duree donnee par docs/specs/instr/CLR.md
- `e06_14_flags_sample` : 3 cas de drapeaux calcules a la main d'apres le manuel (valeurs initiales -> X N Z V C)
