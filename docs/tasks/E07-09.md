## Specification
Implemente `CMP` (b, l, w) dans `crates/puce-m68k/src/insn/i_cmp.rs` et enregistre-la dans `insn/mod.rs` (`pub mod i_cmp;`, ses `RULES`, sa branche de `plan_for` et de `run_hook`).
Sous-taches, dans cet ordre:
1. Decodage: regles (masque, valeur) de tous les encodages LEGAUX de CMP (modes d'adressage valides via `ea.rs`); les autres encodages ne doivent pas etre captures.
2. Plans: pour chaque (taille, mode source, mode destination) legal, un plan de micro-cycles (jetons de `docs/specs/12_PLAN_GRAMMAR.md`, `ea_read_plan`/`ea_write_plan` de `ea.rs`) conforme a `docs/specs/instr/CMP.md`.
3. Semantique et drapeaux (X N Z V C) dans les hooks; fonctions pures partagees dans `alu.rs` si elles servent a plusieurs instructions.
4. Verification: la commande `m68k ssc ... --strict` ci-dessous doit passer (2500 tests par fichier; tests avec address error ignores, D-030).
Source de verite du timing: `docs/specs/instr/CMP.md` puis `docs/specs/instr/_EA.md`. Jamais deviner un timing: question Q&R avec les valeurs en conflit. Les tests SingleStepTests viennent de MAME (D-007).
Note: CMPI idem (a confirmer)

## Tests
Tous les tests sont prefixes par `e07_09_`.

- `e07_09_decode_legal` : tous les encodages legaux de CMP decodent vers cette instruction (comptage exact attendu: calcule-le d'apres les modes valides)
- `e07_09_decode_illegal` : un encodage illegal voisin n'est pas capture
- `e07_09_plan_basic` : le plan du cas le plus simple a la duree donnee par docs/specs/instr/CMP.md
- `e07_09_flags_sample` : 3 cas de drapeaux calcules a la main d'apres le manuel (valeurs initiales -> X N Z V C)
