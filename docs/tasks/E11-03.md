# E11-03 - Address error (frame de groupe 0)
Epopee: E11 | Type: code | Dependances: E11-02 | Taille estimee: ~150 lignes | DIFFEREE (hors v1)

## Contexte
DIFFEREE (D-003): hors perimetre initial; l'utilisateur decide au GATE E11-01 si l'epopee est lancee. Frame de 14 octets (mot de statut, adresse fautive, IR, SR, PC). Active les tests `re`/`we`: retire le skip D-030 du runner pour les fichiers couverts.

## Specification
Detecte l'acces mot/long a une adresse impaire dans le moteur, produit les cycles `re`/`we` (AS non asserte, resultat non commite), puis le traitement d'exception (vecteur 3). Met a jour `ssc::run_test` pour comparer ces tests au lieu de les ignorer.


## Tests
Tous les tests sont prefixes par `e11_03_`.

- `e11_03_odd_word_read` : lecture mot en adresse impaire declenche le vecteur 3
- `e11_03_frame_14_bytes` : 14 octets empiles
- `e11_03_status_word` : mot de statut: FC et bit R/W corrects
- `e11_03_no_commit` : l'ecriture fautive n'est pas commitee
