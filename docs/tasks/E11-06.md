## Specification
Broches RESET/HALT: sequence de reset (SSP, PC depuis les vecteurs 0 et 1), etat halted apres une double faute.


## Tests
Tous les tests sont prefixes par `e11_06_`.

- `e11_06_reset_vectors` : SSP et PC pris aux adresses 0 et 4
- `e11_06_reset_state` : S=1, IMASK=7, T=0
- `e11_06_double_fault_halt` : address error dans un traitement d'exception: halted
