# E12-01 - Desassembleur: infrastructure et formatage des operandes
Epopee: E12 | Type: code | Dependances: E11-14 | Taille estimee: ~140 lignes

## Contexte
Desassembleur sans allocation (feature `disasm`): `pub fn disasm(words: &[u16], pc: u32, out: &mut dyn core::fmt::Write) -> usize` renvoie le nombre de mots consommes; syntaxe Motorola (`move.w d0,(a1)+`, `dc.w $xxxx` pour un opcode illegal).

## Lire d'abord
- `docs/qa/DECISIONS.md` et `docs/qa/FAQ_M68K.md` (a consulter avant toute question)

## Write only in
- `crates/puce-m68k/src/disasm.rs`
- `crates/puce-m68k/src/lib.rs`
- `docs/qa/inbox/**` (questions uniquement)

## Specification
Cree `crates/puce-m68k/src/disasm.rs` (`#[cfg(feature = "disasm")] pub mod disasm;`): table de mnemoniques par `InsnId`, formatage des 12 modes d'adressage (`d0`, `a1`, `(a2)`, `(a2)+`, `-(a2)`, `$10(a2)`, `$10(a2,d3.w)`, `$1234.w`, `$123456.l`, `$10(pc)`, `$10(pc,d3.l)`, `#$12`), suffixes de taille, liste de registres de MOVEM (`d0-d3/a0/a2`).


## Tests
Tous les tests sont prefixes par `e12_01_`.

- `e12_01_ea_all_modes` : les 12 modes formates comme dans la spec
- `e12_01_size_suffix` : .b .w .l
- `e12_01_movem_list` : masque 0x0F0F -> `d0-d3/a0-a3` ou forme equivalente documentee
- `e12_01_illegal_dcw` : opcode illegal -> `dc.w $xxxx`, longueur 1
- `e12_01_no_alloc` : le module n'utilise ni `String` ni `Vec` (grep du source)
