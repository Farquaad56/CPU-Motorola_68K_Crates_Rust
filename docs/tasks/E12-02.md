# E12-02 - Desassembleur: transferts et arithmetique
Epopee: E12 | Type: code | Dependances: E12-01 | Taille estimee: ~140 lignes

## Contexte
Desassembleur sans allocation (feature `disasm`): `pub fn disasm(words: &[u16], pc: u32, out: &mut dyn core::fmt::Write) -> usize` renvoie le nombre de mots consommes; syntaxe Motorola (`move.w d0,(a1)+`, `dc.w $xxxx` pour un opcode illegal).

## Lire d'abord
- `docs/qa/DECISIONS.md` et `docs/qa/FAQ_M68K.md` (a consulter avant toute question)

## Write only in
- `crates/puce-m68k/src/disasm.rs`
- `docs/qa/inbox/**` (questions uniquement)

## Specification
Textes de MOVE/MOVEA/MOVEQ/MOVEM/MOVEP/LEA/PEA/EXG/SWAP/EXT/LINK/UNLK/CLR, ADD/ADDA/ADDX/SUB/SUBA/SUBX/NEG/NEGX/CMP/CMPA/TST/MUL/DIV (et les formes immediates ADDI/ADDQ/SUBI/SUBQ/CMPI).


## Tests
Tous les tests sont prefixes par `e12_02_`.

- `e12_02_move_w` : 0x3011 -> `move.w (a1),d0`
- `e12_02_moveq` : 0x7001 -> `moveq #1,d0`
- `e12_02_lea` : 0x41F9 + abs.l
- `e12_02_addq` : 0x5240 -> `addq.w #1,d0`
- `e12_02_movem_pre` : movem.l d0-d7,-(sp)
- `e12_02_mulu_divs` : mulu.w, divs.w
