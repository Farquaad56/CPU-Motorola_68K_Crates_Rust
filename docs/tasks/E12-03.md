# E12-03 - Desassembleur: logique, decalages, bits, BCD
Epopee: E12 | Type: code | Dependances: E12-02 | Taille estimee: ~140 lignes

## Contexte
Desassembleur sans allocation (feature `disasm`): `pub fn disasm(words: &[u16], pc: u32, out: &mut dyn core::fmt::Write) -> usize` renvoie le nombre de mots consommes; syntaxe Motorola (`move.w d0,(a1)+`, `dc.w $xxxx` pour un opcode illegal).

## Lire d'abord
- `docs/qa/DECISIONS.md` et `docs/qa/FAQ_M68K.md` (a consulter avant toute question)

## Write only in
- `crates/puce-m68k/src/disasm.rs`
- `docs/qa/inbox/**` (questions uniquement)

## Specification
Textes de AND/OR/EOR/NOT et formes immediates, ASL..ROXR (registre et memoire), BTST/BSET/BCLR/BCHG, ABCD/SBCD/NBCD.


## Tests
Tous les tests sont prefixes par `e12_03_`.

- `e12_03_and_w` : and.w d1,d0
- `e12_03_lsl_imm` : lsl.w #2,d0
- `e12_03_asr_mem` : asr.w (a0)
- `e12_03_btst_imm` : btst #3,d0
- `e12_03_abcd` : abcd d1,d0 et abcd -(a1),-(a0)
