# E12-04 - Desassembleur: controle de flux et systeme
Epopee: E12 | Type: code | Dependances: E12-03 | Taille estimee: ~140 lignes

## Contexte
Desassembleur sans allocation (feature `disasm`): `pub fn disasm(words: &[u16], pc: u32, out: &mut dyn core::fmt::Write) -> usize` renvoie le nombre de mots consommes; syntaxe Motorola (`move.w d0,(a1)+`, `dc.w $xxxx` pour un opcode illegal).

## Lire d'abord
- `docs/qa/DECISIONS.md` et `docs/qa/FAQ_M68K.md` (a consulter avant toute question)

## Write only in
- `crates/puce-m68k/src/disasm.rs`
- `docs/qa/inbox/**` (questions uniquement)

## Specification
Textes de Bcc/BSR/DBcc/Scc/JMP/JSR/RTS/RTR/RTE/NOP/STOP/RESET/TRAP/TRAPV/CHK, MOVE to/from SR/CCR/USP, ANDI/ORI/EORI to SR/CCR, TAS, ILLEGAL. Les cibles de branchement sont affichees en adresse absolue calculee depuis `pc`.


## Tests
Tous les tests sont prefixes par `e12_04_`.

- `e12_04_beq` : beq.s avec deplacement 8 bits -> cible absolue
- `e12_04_bra_w` : bra.w avec mot d'extension
- `e12_04_dbf` : dbf d0,target
- `e12_04_jsr_abs` : jsr $1234.l
- `e12_04_rts_nop` : rts / nop
- `e12_04_trap` : trap #15
- `e12_04_move_sr` : move sr,d0 / move d0,sr
