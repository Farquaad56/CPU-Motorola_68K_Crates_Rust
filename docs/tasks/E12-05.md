# E12-05 - Desassembleur: couverture des 65536 opcodes
Epopee: E12 | Type: code | Dependances: E12-04 | Taille estimee: ~90 lignes

## Contexte
Garde-fou: le desassembleur et la table de decodage doivent s'accorder pour tous les opcodes.

## Lire d'abord
- `docs/qa/DECISIONS.md` et `docs/qa/FAQ_M68K.md` (a consulter avant toute question)

## Write only in
- `crates/puce-m68k-machines/tests/disasm_all.rs`
- `docs/qa/inbox/**` (questions uniquement)

## Specification
Test d'integration `crates/puce-m68k-machines/tests/disasm_all.rs`: pour chaque opcode 0..=65535 (avec des mots d'extension de test), `disasm` ne panique pas; un opcode que `decode` classe ILLEGAL donne `dc.w`, un opcode decode donne un mnemonique commencant par celui de la table.


## Tests
Tous les tests sont prefixes par `e12_05_`.

- `e12_05_no_panic` : 65536 opcodes sans panique
- `e12_05_illegal_matches_decode` : dc.w exactement pour les ILLEGAL
- `e12_05_length_matches` : la longueur desassemblee = 1 + nombre de mots d'extension de ea.rs
