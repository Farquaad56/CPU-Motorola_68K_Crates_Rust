# E14-01 - Liaison wasm-bindgen du coeur
Epopee: E14 | Type: code | Dependances: E13-09 | Taille estimee: ~120 lignes

## Contexte
Expose le coeur a JavaScript (demo sans serveur). Dependance autorisee: `wasm-bindgen` (cible wasm32 seulement).

## Lire d'abord
- `docs/qa/DECISIONS.md` et `docs/qa/FAQ_M68K.md` (a consulter avant toute question)

## Write only in
- `crates/puce-m68k-wasm/src/lib.rs`
- `crates/puce-m68k-wasm/Cargo.toml`
- `Cargo.lock`
- `docs/qa/inbox/**` (questions uniquement)

## Specification
`crates/puce-m68k-wasm/src/lib.rs`: struct `Machine` (RAM plate 16 Mio ou 1 Mio configurable, `Cpu`), methodes `load(bytes)`, `step()`, `step_clock()`, `regs_json()`, `disasm(addr, n)`, `mem_hex(base)`, `buslog_json()`. Les calculs restent dans le crate; le JS ne fait que de l'affichage.


## Tests
Tous les tests sont prefixes par `e14_01_`.

- `e14_01_native_step` : la logique `Machine` est testable en natif: step d'un NOP avance le PC
- `e14_01_regs_json` : regs_json contient pc
- `e14_01_disasm_rows` : disasm(0, 3) = 3 lignes
- `e14_01_load_bounds` : binaire trop grand -> erreur
- `e14_01_buslog` : apres un step le journal n'est pas vide

## Acceptance
```acceptance
cargo test -p puce-m68k-wasm e14_01_
cargo build -p puce-m68k-wasm --target wasm32-unknown-unknown
```
